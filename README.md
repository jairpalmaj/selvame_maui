# Aplicación Móvil "Selvame"

## Características Principales

* Detecta 6 diferentes clases (papel, cartón, vidrio, basura, plástico, metal) por medio de una fotografía.
* Incluye un modelo entrenado con TrashNet y MobileNetV3-Large por medio de Learning Transfer y el formato ONNX.
* Disponible para iOS y Android.

## Stack Tecnológico

* .NET MAUI / XAML
* ONNX Runtime / MobileNetV3 / TrashNet
* SQLite
